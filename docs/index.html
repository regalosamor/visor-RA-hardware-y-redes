          Cómo usar el laboratorio

          • Biblioteca: arrastra archivos .glb o añade una URL HTTPS con CORS habilitado.
          • Explorar 3D: arrastra para rotar, rueda o pellizco para zoom, dos dedos para desplazar.
          • RA: en móviles compatibles (Android con ARCore, iOS con Quick Look) coloca el modelo sobre tu entorno.
          • RV: recorre el laboratorio con WASD y ratón; con visor WebXR usa "Entrar con visor".
          • Puntos: escribe un texto, pulsa FIJAR PUNTO y haz clic sobre el modelo.
          • IA: genera un prompt pedagógico y cópialo en tu asistente preferido.
          • Atajos: 1 3D · 2 RA · 3 RV · Esc cancela fijar punto.
